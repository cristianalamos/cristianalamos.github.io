## Inline Math

The Pythagorean theorem states that $a^2 + b^2 = c^2$ for any right triangle with sides $a$, $b$, and hypotenuse $c$.

## Display Equations

We can also write display equations. For example, the fundamental theorem of calculus:

$$\int_0^1 x^2\,dx = \frac{1}{3}$$

## Code Highlighting

Here's a simple Python function with syntax highlighting:

```python
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

print(fibonacci(10))
```

The kramdown and Rouge combination provides clean syntax highlighting out of the box.
